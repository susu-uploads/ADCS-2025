## Дополнительные материалы

#### Дополнительные материалы:

- [Distributed Systems: Concepts and Design](https://edu.susu.ru/mod/resource/view.php?id=8137156)

2012 г. Описаны основные концепции распределенных вычислительных систем, методы коммуникации, основные концепции
организации РВС, алгоритмы синхронизации времени, согласования состояния и репликации данных.

- [Введение в распределенные вычисления](https://edu.susu.ru/mod/resource/view.php?id=8137157)

В пособии излагаются основные понятия и концепции из области распределенных вычислений, для модели асинхронных
распределенных систем приводятся методы и алгоритмы решения наиболее важных задач. Особое внимание уделяется механизму
логических часов, позволяющему значительно упростить разработку алгоритмов для распределенных систем.

- [Подходы к проектированию RESTful API](https://edu.susu.ru/mod/resource/view.php?id=8137158)

В [этой статье с habrahabr](https://habrahabr.ru/company/dataart/blog/277419/) представлен опыт проектирования RESTful API — на конкретных примерах показано, как делать хотя бы простые сервисы красиво.

- [Знакомство с Apache Spark](https://edu.susu.ru/mod/resource/view.php?id=8137159)

Обзорная статья о возможностях фреймворка для обработки больших объемов данных Apache Spark.

- [Distributed systems for Fun and Profit](https://edu.susu.ru/mod/resource/view.php?id=8137160)

Краткое (58 страниц) и очень доходчивое введение в основные концепции и алгоритмы распределенных систем.

- [Alex Borysov об gRPC](https://edu.susu.ru/mod/resource/view.php?id=8137161)

Презентация Александра Борисова (Software Engineer @ Google) конференции JokerConf (2017 г.), посвященная технологии
Google gRPC.
